# x402 pay-per-request on Stellar

nata exposes one paid endpoint as a demo of [x402](https://developers.stellar.org/docs/build/agentic-payments/x402) on Stellar: an agent calls the URL, gets `HTTP 402` with the price, signs a Soroban authorization entry for a SEP-41 token transfer, retries, and gets the data.

| | |
|---|---|
| Endpoint | `GET /api/x402/campaigns-premium` |
| Content | Active campaigns plus `fillRate`, `claimsLeft` and total remaining budget (the free `/api/campaigns` does not compute these) |
| Scheme | `exact` (`@x402/stellar`, `ExactStellarScheme`) |
| Network | `stellar:testnet` (default) or `stellar:pubnet` |
| Asset | Any SEP-41 token. Defaults to the app token (`NEXT_PUBLIC_TOKEN_CONTRACT_ID`, vUSD on testnet) |
| Default price | `0.01` token (100000 raw units, 7 decimals) |

## How it works

1. No `X-PAYMENT`/`PAYMENT-SIGNATURE` header: the route answers `402` with a `PAYMENT-REQUIRED` header (base64 JSON: scheme, network, `payTo`, token contract, amount).
2. The client (`@x402/fetch` with `@x402/stellar/exact/client`, or any x402 v2 client) signs the auth entry. It never submits a transaction.
3. The route sends the payload to the facilitator `/verify`. Only a valid payment reaches the handler.
4. If the handler answers 2xx, the facilitator `/settle` submits the transfer and pays the fee. A non-2xx answer settles nothing.

Code: `apps/web/lib/server/x402.ts` (settings, pure), `x402-gate.ts` (`withX402` wiring), `app/api/x402/campaigns-premium/route.ts`.

## Configuration (server only, see `.env.example`)

| Variable | Meaning |
|---|---|
| `X402_PAY_TO` | Receiving `G...` account. Needs a trustline to the token issuer. Unset means the route answers `503` (never serves for free). |
| `X402_ASSET` | SEP-41 contract id. Defaults to `NEXT_PUBLIC_TOKEN_CONTRACT_ID`. |
| `X402_PRICE` | Whole tokens, default `0.01`. |
| `X402_NETWORK` | `stellar:testnet` (default) or `stellar:pubnet`. |
| `X402_FACILITATOR_URL` | Default `https://www.x402.org/facilitator` (Coinbase, testnet only). OpenZeppelin: `https://channels.openzeppelin.com/x402/testnet` (testnet), `https://channels.openzeppelin.com/x402` (mainnet). |
| `X402_FACILITATOR_API_KEY` | Bearer key for the OpenZeppelin facilitator. Keep it out of git. |

## Trying it on testnet

1. Set `X402_PAY_TO` to a funded testnet account with a vUSD trustline (use the faucet flow).
2. `curl -i http://localhost:3000/api/x402/campaigns-premium` shows the `402` and requirements.
3. Pay with an x402 client holding vUSD, for example the `@x402/fetch` client from the [Stellar quickstart](https://developers.stellar.org/docs/build/agentic-payments/x402/quickstart-guide), pointing at this URL.

## Tests

`pnpm test` in `apps/web` covers settings parsing, price conversion and the unpaid `402` response against an offline stub facilitator. No funds or network are needed.

## Not verified
